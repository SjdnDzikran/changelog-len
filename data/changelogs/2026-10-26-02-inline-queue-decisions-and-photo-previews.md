Reviewing attendance requests gets faster for admins, and submitted evidence is now visible without leaving the page.

- **One-click decisions:** Pending leave, permit, overtime, visit, and work report requests now show an approve/reject dropdown directly in the queue table's status column, like the old admin reports. No more opening each request just to make a decision.
- **Photo previews in place:** Clicking an evidence thumbnail (check-in selfie, check-out photo, or visit photo) now opens the full image in a pop-up window on the same page instead of jumping to a new browser tab, so admins can review evidence without losing their place in the list.
- **Cleaner buttons:** Menu and filter buttons across the app now share the same rounded shape and size as the rest of the interface, for a consistent look on every page.
