- **"Pembaruan Aplikasi" page:** A new page under the System menu where admins can view the latest release, upload new APK files, and browse the full release history
- **Version highlight card:** The latest published version is shown prominently at the top with its release notes, file size, and a one-click download button
- **Drag-and-drop upload:** New releases are uploaded by entering a version number, optional release notes, and selecting an APK file, all within the same page
- **Searchable release history:** Past releases are listed in a table with search, showing version, file size, date, and download links
