- **Drag-and-drop or click to upload** photos for each serial number in the Tested Inventory detail modal, with automatic validation for file type and size
- **Thumbnail gallery** shows all attached photos alongside each serial number, with a delete button for authorized users
- **Full-screen image viewer** with scroll-wheel zoom, mouse and touch pan, 90-degree rotation, carousel navigation between photos, keyboard shortcuts, and a download button
- **Photo count badge** on each serial number row in both the main Tested Inventory table and the Per S/N report page
- Loading spinners indicate when photos are being fetched, and uploads are restricted to Recorded status only
