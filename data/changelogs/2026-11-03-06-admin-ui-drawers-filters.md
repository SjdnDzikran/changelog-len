**Detail drawers instead of page jumps:** Clicking any row in the admin tables (roles, employees, attendance records) opens a side panel with the full details, actions included, so managers no longer navigate away from the list to review one record. Rows are keyboard-accessible too.

**Cleaner action buttons:** Row actions collapsed into a single "more" menu with icons; destructive actions (delete) sit last and always ask for confirmation. Primary buttons moved into the page heading with a consistent look across all admin pages.

**Color-coded approvals:** Status badges are now meaningful at a glance: active employees in green, warnings in amber, destructive actions in red. The permission matrix for roles was rebuilt as a single scannable table with checkboxes per module, an unsaved-changes highlight, and a sticky save bar.

**Unsaved-change protection:** A proper confirmation dialog now appears when navigating away from any admin form with unsaved edits, in both languages, replacing raw browser popups. A guard covers every admin and account form, including profile photo editing.

**Polished inputs and filters:** Filters moved inline into each page's heading row; a new month picker replaces clunky month inputs; time fields, number steppers, currency amounts, and file choosers were upgraded to modern animated controls with warning hints when values hit limits.
