Document numbers for AWB and DRS are generated by looking up the highest existing number and adding one. When two staff members created a document at exactly the same moment, both could read the same highest number and receive identical numbers.

- **Duplicate numbers eliminated:** Document number generation now locks the sequence while a number is being issued, so two simultaneous creations can never receive the same AWB or DRS number
- **Applies everywhere numbers are issued:** Manual AWB creation, booking-based AWB creation, and daily DRS numbering all use the same protection
- **Cleaner records:** Prevents the downstream confusion of two shipments sharing one document number, which previously required manual correction
