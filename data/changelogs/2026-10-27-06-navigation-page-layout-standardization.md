- **Breadcrumbs in the header:** Every admin page now shows clickable breadcrumbs (Home, Employees, Edit employee, and so on) in the top bar, replacing the old per-page back links, so you always know where you are.
- **Proper page titles in the browser:** The browser tab now shows the current page name in Indonesian or English, following the selected language.
- **Consistent page width:** Employee pages (dashboard, punch, history, schedules, work reports) all share the same centered width, instead of each page looking different.
- **Tidier tables:** All admin list pages (employees, attendance, leave, permits, visits, overtime, work reports, salaries, payroll) got a unified footer with record counts on the left and page controls on the right, flatter tables without extra boxes, and centred detail pages.
- **Clearer naming:** The daily report is now simply called "Today's attendance", and the app is branded "LEN Attendance" throughout.
