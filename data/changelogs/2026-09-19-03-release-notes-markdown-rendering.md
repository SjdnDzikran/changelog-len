Release notes on the app updates page are now displayed as formatted text instead of a plain block of characters.

- **Rich formatting:** Headings, bullet and numbered lists, quotes, code snippets, and clickable links in release notes all render properly, matching how they were written
- **Easier to read:** Notes authored for the TMS and WMS mobile apps now display the same way they do elsewhere in the admin panel, so staff can scan what changed in each release at a glance
