**No more technical codes:** The attendance settings timezone field was a free-text input that required an exact technical name like "Asia/Jakarta". It is now a dropdown offering the three Indonesian timezones with familiar labels: WIB, WITA, and WIT.

**Safe by design:** Any timezone already saved in the system remains selectable even if it is not in the standard list, so existing configurations cannot be broken by the change.
