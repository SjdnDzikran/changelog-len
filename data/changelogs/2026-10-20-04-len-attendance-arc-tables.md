All the main data tables in the attendance and payroll screens have been upgraded to a new sortable table design, with a more capable filter toolbar:

- **Sortable columns:** Click any column header to sort employees, salaries, attendance history, payroll runs, requests, and roles ascending or descending. The sorted column is highlighted, and rows glide into place instead of jumping.
- **Filter chips:** Active filters now appear as removable chips in a toolbar, with an "Add filter" menu for picking filters and values, replacing plain dropdowns. Filters and page selection live in the page address so filtered views can be shared and survive refreshes.
- **Better pagination:** Page numbers you can click directly, with clear previous/next controls, replacing the old previous-only paging.
- **Mobile-friendly tables:** On phones, tables fold into readable cards automatically, and the column headers become a strip of sort buttons so sorting stays one tap away.
- **Clearer admin navigation:** Every admin menu item now has its own distinct, meaningful icon instead of most sections sharing the same one, making the sidebar easier to scan.
