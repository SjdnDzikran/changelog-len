Clicking a column header on any admin table now sorts the complete list, not just the page on screen.

- **True ordering:** Sorting an employee, attendance, leave, overtime, visit, work report, payroll, or salary table reorders every record before the page is cut, so page one always holds the true top entries
- **Sort by what matters:** Employees can be ordered by name, email, ID number, position, or location; records by date, status, or the amounts on payroll and salary tables
- **Three-click cycle:** Click once for ascending, again for descending, a third time to clear the sort and return to the default order
- **Sort survives navigation:** The chosen sort is kept in the page address, so refreshing or sharing the link keeps the same view
