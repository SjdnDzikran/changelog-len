Download buttons on two pages looked normal but did nothing when clicked, leaving users unable to get the files in front of them:

- **APK downloads working again:** The "Unduh APK" button on the app updates page, plus the small download icon next to each release in the list, now respond to clicks so staff can actually download the latest app version
- **Petty cash attachments fixed:** In the attachment preview window, the "open in new tab" and "Download" buttons now work again, including the download button shown as a fallback when a file type can't be displayed on screen
- **Released as app version 1.24.6:** The fix ships with new release notes visible in the app update screen, so users know why they should update
