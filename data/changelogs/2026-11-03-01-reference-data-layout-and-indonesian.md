**Tables fit any screen:** All ten Reference Data pages were cramped by the side navigation, pushing action buttons (Edit, status, Add, Fix links) outside the visible area. The page now uses the same layout and margins as other admin pages, and table action columns stay pinned to the right edge while scrolling, so buttons are always clickable without horizontal scrolling first.

**Compact section chooser:** The permanent side navigation rail was replaced by a collapsible "Pilih data referensi" menu above the content, freeing the full page width for the tables. All ten reference pages (locations, moda, tariffs, materials, storage, and others) remain reachable with keyboard and mouse.

**Bahasa Indonesia throughout:** Navigation, page titles, breadcrumbs, dialog headings, explanatory text, import instructions, filter and pagination text are now in Bahasa Indonesia. Table column names, form field labels, and action buttons keep their existing wording, and no business data or stored values changed.

**Release 1.26.3 shipped:** The patch is bundled as release 1.26.3 with release notes attached, verified by the full Reference Data test suite and 70 responsive layout checks across desktop, tablet, mobile, and enlarged-text conditions.
