Search boxes throughout the admin screens have been reworked so results refresh automatically after you pause typing, replacing the old "type and press Enter" workflow, with a matching visual style everywhere.

- **Search as you type:** Results now update automatically about a third of a second after you stop typing, and pressing Enter still jumps straight to the results if you prefer
- **One consistent search box:** The employee, location, and payroll screens previously used three different search box styles; all now share a single design with an icon and a clear (×) button, and the clear button keeps your cursor in the field for the next search
- **Works with any keyboard:** Fast typists using Asian input methods (composition typing) no longer trigger half-finished searches; results only update once the full word is entered
- **Focus stays put:** Clicking the clear button or finishing a search no longer throws keyboard focus to an unexpected place, so you can keep typing immediately
- **Clearer labels:** Search placeholders now say exactly what to look for, for example "Search by location name"
