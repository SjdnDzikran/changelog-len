A set of dark-mode readability fixes across the TMS web app, released as UI 2.0.8.

- **Login stays readable after sign-out:** Login fields and browser-saved autofill text keep the light login card's colors even when the app theme is dark, so nothing disappears into the background
- **Clearer notifications:** Toast notifications now pair text and icons with matching backgrounds for info, success, warning, and error messages, so every notification is readable in dark mode
- **User creation form:** The role list in Create User no longer shows as a white block in dark mode and follows the active theme
