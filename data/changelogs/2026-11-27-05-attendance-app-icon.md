The Attendance web app now uses a dedicated icon that belongs to the LEN Logistics app logo family.

- **A recognizable mark:** the new icon combines a clock set to 08.00 (start of the workday) with the rising arrow from the LEN logo, on the same navy tile as the other LEN apps, so Attendance is instantly distinguishable from its sibling apps on a phone home screen or browser tab
- **Consistent everywhere:** the icon is regenerated for every size and platform: browser favicon, Android home screen, iOS home screen, and the large 1024-pixel source file used for app stores
- **Playful detail kept:** hovering the icon runs the minute hand once around the dial, and it respects the system setting for reduced motion
